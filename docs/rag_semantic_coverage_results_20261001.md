# 语义缺失与覆盖代理开发结果

## 本轮完成

改进了证据干预构造：按同义、重复、间接支持删除句段，生成前两次核验，要求目标事实 absent、其他必要事实 supported。9 道预设筛查题中 4 道合格，分别为 fin_005、fin_006、fin_021、fin_025；另外 5 道筛查失败完整保留。

合格题每题生成原上下文、语义缺失、前置无关文本但保留证据三个条件，共 **12 条新回答**。两个完整证据条件共 8 条均质量 2；4 条语义缺失回答均质量 1，均未触发拒答规则。

开发了不读取冻结标准答案/事实清单的覆盖代理。补充检索输入为问题和实际可见来源，从原 40 题的正常证据缓存重排取证据，再提取临时核查要点。标准事实只用于离线干预和结果评价。该检索库仍来自原题缓存，不能等同于独立生产知识库验证。

## 三版代理结果

|方案|可确定结果/12|4 条不完整回答中检出|确定漏报|不完整 U|8 条完整回答误报|完整 U|
|---|---:|---:|---:|---:|---:|---:|
|只看问题和回答|5|0|1|3|0|4|
|补充检索首版|7|2|0|2|2|3|
|补充检索第二版|9|2|1|1|0|2|
|补充检索第三版|12|4|0|0|0|0|

首版把可选性能细节加入必要要点，产生完整答案误报；第二版缩小到最低必要集合并携带具体原文数值，但出现“原文支持了事实”被误当成“回答覆盖了事实”的评价目标错误。第二版还因真实短标题不到预设 8 字，把三条回答的依据置为 U。

第三版修复：只把实际存在的短摘录扩展为相邻完整原文句段，保留偏移和原摘录；明确评价对象为回答；covered/partial/contradicted 必须引用回答中的真实文字；两次分类不一致或摘录不真实则 U。无需新增人工标注。

**第三版的 4/4 与 0/8 是同一批开发回答上的结果。第二、三版是在查看前版问题后修订，复用了初次生成的 12 条回答，不能把三个版本相加成 36 条样本，也不能宣称独立测试达到 100% 检出或已验证长期误报率。**

新来源核查组 fin_013、fin_023、fin_024 未产生合格干预。fin_013 的多个参数同在一句，整句删除破坏全部参数；fin_023 一次基线核查的摘录改写了原文，严格验证保留 U；fin_024 删除连带破坏了其他必要事实。因此本轮没有取得新来源的有效配对验证，不能声称已验证推广效果。

## 执行与验证

195 个响应 ID 全部唯一，累计 360073 token。请求模型别名 deepseek-chat，195 次响应实际模型均 deepseek-flash。12 次回答生成全部正常结束；所有阶段的数据、代码、模型哈希、字段白名单、阶段顺序审计通过。总审计从原始响应重算了每条答案的质量、拒答与三版代理结果。

相关测试 **31 项通过**。原实验数据保持冻结；本轮新增代码、报告、汇总和图片同步到备份仓库。完整题目、证据、答案、API 原始记录留在项目结果目录中。

DeepSeek 同时负责生成和评价，两次核查不是独立人类审阅。第三版的语义判断仍可能偏差。相关性缺口仍有盲区：fin_006 的回答降质后 512/4096 分数都没有增大；fin_025 的降质仅带来很小变化，而证据保留前缀使 512 token 分数大幅增大。
