# V9附加检查与后续安排

## 程序字面交叉检查

不再调用API，按回答中明确字段标签提取展示数字。正常10/10的目标值等于正常来源，故障10/10的目标值等于人为修改后的值；20/20回答的其他数值字段保持正常来源值。

该检查在回答产生后进行，仅检验字段下数字量级，不验证单位解释、实体语义或原文真值，不合并到主评价规则。第一次临时解析删除全部空白，导致前一数字与下一条编号拼接；错误诊断记录已保留，随后解析保留换行和空白。主评分与主结果未改变。新解析器2项测试通过。

## 当前证据支持的结论

真实生成端数值扰动造成10/10配对质量下降；10条故障回答都直接给出错误数值，没有拒答。正常原文核对检出10/10，而拒答信号在这10条错误上没有触发。正常完整答案0/10误报。该结论只针对10道通过严格干预筛查的已见题目和8篇已有来源，不能推广到全部17题或自然流量。

## 下一阶段安排

先冻结低频、间歇错误的混合序列方案，再采集新回答。把正常序列用于校准，阈值冻结后用另一批新序列测试；按论文分组，记录跨日/模型实际版本与全部未定。

比较简单拒答、首次核对异常、滑窗、CUSUM和e-detector，在相同误报限制下报告检测率、延迟、变前误报及未定。需要更长的纯正常流量评估误报；本轮0/10不能验证5%以下误报水平。不能把本轮20条答案重复拼接、重抽样后当作独立新流量，也不能以全错故障的容易检出表现声称变点算法优越。

本轮完成机制验证，尚未执行下一阶段序列实验。全部知识库/监测依据同步污染仍另属适用范围。自动评价限定保留，无需新增人工复核。
