# 真实数值证据故障V9预设协议

本轮使用V8.2的17题与固定正常检索缓存，P0002采用单例开发后明确的第3数据列题干。已有问题与论文，仅验证生成端证据受扰动的机制。

## 干预和准入

固定每题第1个数值字段，整数加1，小数加最后一个展示位的一个单位；百分号不变。只修改正常临时核对依据中引文的唯一目标数值，所有重复引文同步修改。存在原数值残留时保守排除，包括其他对象碰巧同值的情况；不全局替换同值数字。

17题全部保留筛查记录，结构合格10题。结构合格题在任何待测回答生成前，仅凭问题、公开字段和故障证据盲提取，做两轮字段与来源检查。要求变更目标值符合预设、其他必答字段与正常依据等价。准入至少8对、6篇论文；失败就停止生成。

## 配对与评价

准入题各产生1条正常和1条故障新回答；固定种子2026100209打散载荷顺序。模型请求deepseek-chat，温度0、最大512 tokens，四工作线程；记录实际响应模型。最多34条新生成，本轮结构筛查已将上限收敛为20条。

评分沿用现有两轮自动字段核对与实际答案引文核验。离线参考来自正常原文；监测临时依据仅来自冻结正常检索。故障提取计划仅用于生成前资格检查，不能作为监测或真值。API请求不传故障条件标签。

## 预设结果门槛

正常完整比例至少80%；正常完整转故障不完整至少60%（所有准入对为分母）；故障实际不完整答案检出至少80%（含其核对U）；正常完整答案误报为0；回答质量U比例不超过10%。所有U、筛查失败、答案与评分保留，不能按结果选题或重试替换答案。

## 限定与后续

来源按MinerU文本与同一供应商自动评价，不能声称独立真值。严格数字残留筛查会缩小适用范围。本轮使用真实新生成的故障答案，不是合成答案，不是长序列变点检验。全部知识库或监测依据同步污染不在本轮范围。

门槛通过才安排冻结长序列协议、分开校准与测试，并比较拒答、首次核对异常、滑窗、CUSUM和e-detector。本轮配对不能反复拼接成独立流量。
