# 隐蔽故障小规模配对试验预设协议

本轮承接事后方法对照，先验证证据干预、实际答案质量与可观测代理之间的关系。没有在本轮运行长序列变点检测器。

## 选题与冻结

从此前已经获准发送至DeepSeek的40题中，依据已冻结的MinerU自动判分事实，选择至少2个必要事实、对应逐字引文均实际出现在正常可见上下文、可以删除一个事实的引文所在句子并保留其余引文的题目。同来源文献最多1题。

13题满足句子删除的结构条件，最终选取11题、11篇不同文献；没有查看本轮生成答案来选题。原题库、既有判分事实和原论文文件不修改。引文结构只用于准备，不能替代语义核查。

结果目录为 `results/rag_fault_40_live_20260927/subtle_fault_pilot_20261001`；44份输入、条件私钥、复制的判分事实、局部删除记录、异源证据来源与本地特征已在任何API请求前冻结并哈希。

## 四个条件

1. baseline：原正常可见上下文。
2. partial_evidence：选择总删除字符最少的一项必要事实，删除包含其引文的完整句子及重复出现；其他必要引文保留。实际语义是否缺失由生成前证据核查判断，不预先宣布干预成功。
3. near_topic：从其余已授权题的正常证据中排除原来源、排除含任一必要引文的材料，使用本地BGE选最相关的异源上下文。它可能仍支持部分必要事实，可能不引起质量下降，全部如实保留。
4. retained_evidence_prefix：在正常证据前放入不超过400字的异源证据片段，保留全部原正常内容与必要引文，引用编号顺延。该对照检验前置干扰的影响；若生成质量下降，不将它称为已成功的无害对照。

## 信号与评价

- 拒答：既有固定explicit_refusal规则。
- 上下文相关性：同一本地BGE分别使用512与4096token上限，转换为1-sigmoid(logit)。44份输入均在512发生截断，在4096均无截断（最长2212token）。较长输入只解决可见范围问题，不使相关性等于正确率。
- 自动证据审计44次，在新答案生成前完成。对每个必要事实返回supported/partial/absent/U，并逐字校验supported的上下文引文。
- 每条件单独生成答案，共44次；请求别名deepseek-chat，固定原问答提示、temperature=0、max_tokens=512，保存实际响应标识和完成原因。
- 答案质量双轮评价88次，按冻结的必要事实给0/1/2/U；另做44次实际上下文支持评价。两轮来自同一服务，属于重复自动测量。
- 所有生成与评价请求均不携带条件、qid和删除目标编号。完整答题成功仅按质量2定义，拒答标签单独分析，避免以监控信号反过来定义真值。
- 总计220个预定响应：44证据审计、44生成、88质量评价、44支持评价。已有原文判分依据直接复用，不再调用API重新出题或改写依据。

## 分析与后续决策

保留所有44份输入的结果，包括干预不符合设计、正常回答本身不完整、对照影响答案和自动评价未定项。按同题比较质量等级变化，报告可判配对分母；未定项范围不称置信区间，不拟合代理分类阈值。

只有当干预符合预期并确实降低质量后，才讨论其作为后续故障流的适用性。若质量下降但拒答不增加，说明主信号存在覆盖局限；若相关性对故障和保留证据对照都敏感，需要改进代理特异性。新的代理设计需独立开发/校准，再以新冻结序列验证。

本轮属于固定题池、精选结构案例的受控机制试验，不能估计自然线上误报率、检出率或泛化能力。后续长序列范围由本轮机制结果确定，不自动追加大批付费请求。
