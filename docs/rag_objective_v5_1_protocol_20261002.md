# 明确字段题 V5.1：自动评分协议

## 范围与授权

从原40题池已授权的论文证据中生成12个新客观候选，每题2至3个数值或名称字段。用此前12组论文的原始MinerU片段；没有使用之前生成的答案来修改题干或事实。用户已明确允许自行决定候选生成数量，并要求自动评价。

新题涉及已用论文，只能作为新问题上的开发验证。候选保持pending，自动双审通过后仅用于本轮实验。

## 答案生成前的修订

初稿出现请求四项而依据只列三项的情况，两轮自动审查均未指出；另有题干引文不连续、集合/公式不符合标量规则的情况。保留原始初稿和审查。另锁定scope_revision_lock.json：只用原题干和公共字段提取论文内定位范围，再由程序按字段标签构造完整请求，重做两轮来源核查。此修订在任何测试答案生成或评分之前完成，原门槛未降低。

最终11题通过，1道公式候选未通过。

## 固定流程

1. 锁定代码、原始来源、模型和输入哈希。
2. 生成候选、程序校验引文和字段、两轮源文审查。
3. 按公共字段限定范围，重新审查并锁定题目与规范事实。
4. 全文检索仍使用2000字符窗口、1500步长、字符TF-IDF前20候选、BGE 4096 token重排取前3段，按公开论文名称限定来源。规范字段值不参与检索。
5. 按题干的固定字段提取临时检索事实并双审，缺失依据保留U。
6. 锁定33条控制回答：11条完整、11条删除第一项、11条只改错第一项；程序确定真值。再生成11条真实RAG正常查询回答，temperature=0、max_tokens=512及系统提示与前轮一致。
7. 固定索引逐项评价，不允许合并或遗漏事实行。最多一次无效格式重试和一次仅复制引用的修正；语义分歧不自动重试。完整性总分从逐点状态导出。
8. 追加的“带固定事实依据评分”诊断也在真实答案生成前锁定：比较33个控制回答的已知标签与评分器0/1/2结果。它只验证带依据的评分，不能当作无标注覆盖代理的检出率。
9. 从原始API响应重算全部分数与控制标签，核验公开输入白名单、来源片段位置和时序。

## 预设门槛

候选范围/检索代理：至少10道通过来源审查；来源审查通过比例至少80%；控制回答代理U不超过20%；完整对照误报为0；遗漏和改错两类对照的检出比例分别至少80%，U计未检出。

固定事实评分诊断：至少30条已知对照，0/1/2精确一致比例至少95%，U比例不超过10%。二者分别判断，不将前者未定项从分母剔除。
