# v2.1.0 发布说明

（GitHub Release 文案：复制粘贴到 Releases → Draft a new release → 说明框）

自 v2.0.0（初版开源）以来的更新：

## 新功能

- **Word 导出与引用格式转换**：正文引用可二选一——
  - 著者-年份：`[1]` → `（作者，年份）`，多引合并、中文括号内不重复加括号；
  - 上标编号：`[1]` 渲染为 Word 上标；
  - 编号→作者/年份自动映射（解析参考文献列表，兜底导出编号侧车）。
- **论文格式排版**（依据中南财经政法大学硕士学位论文《排版与印刷要求》，全部可覆盖）：
  - 页面：A4，页边距 上/左 30mm、下/右 25mm，页眉小五宋体（距边 15mm），页码小五 Times New Roman 页脚居中；
  - 四级标题：章标题黑体三号加粗居中 / 节标题黑体小三居左 / 目标题宋体四号加粗居左 / 三级目标题黑体小四缩进，段前段后与行距按规范；
  - 正文：宋体小四 + 西文 Times New Roman 12 磅，两端对齐，1.5 倍行距，首行缩进 2 个汉字字符；
  - 表格内文字宋体五号；
  - 编辑器导出弹窗提供正文/标题/页面设置全部可选项，默认即学校规范。

## 修复

- 标题字体被模板主题字体覆盖（Word 中显示为 MS Gothic）：清除 rFonts 的主题字体引用，并 run 级显式设置中英文字体；
- 标题序号与题名间的全角空格在部分 Word 环境渲染为方块：改为序号与题名直连。

## 工程

- 新增 GitHub Actions 自动化测试（push 触发，瘦身依赖，秒级到分钟级）；
- 测试 99 → 100 项，全量通过。
