# 稀疏数值故障序列V10预设协议

## 数据与阶段

固定V9通过干预检查的10题/8篇已有论文，按来源均衡分为4篇校准、4篇测试，每组5题。两组论文在开发中已经见过，只是本轮来源分开。正常与故障证据、参考和正常监测依据沿用冻结资料。

生成计划共2480条：均值校准80条（4条20步流）；正常阈值校准12条40步流；正常测试30条40步流；故障测试18条40步流（10%、30%、60%各6条）。第16步之后按独立预设PRNG子流的Bernoulli概率注入已验证数值故障。实际零注入故障流也保留，不按结果替换。

按均匀选来源、再选题抽取，全部计划和方法在新数据之前冻结。测试流启动顺序预设打散；流内处理串行，不按报警停止采集。参考和监测依据均保持正常；全知识库同步污染不适用。

## 新生成与评分缓存

每个位置调用生成API，最多2480条，配置沿用deepseek-chat、温度0、最大512 tokens、四线程，记录实际模型与唯一响应ID。题目与证据已在此前授权范围，沿用用户自行决定数量及联网验证授权；不上传密钥。

每个答案即时核对，处理完成才允许该流下一次生成。只有问题原文、答案全文、完成原因、正常参考事实和正常监测事实完全相同，才共享本轮两轮评审缓存；不复用V9回答或评分。缓存规则先冻结，U也按缓存固定保留；两轮一致不属于独立人工真值。

## 校准和方法

核对incomplete=1、complete=0、U=1且单列；拒答作为基线。均值上界m仅使用80条均值校准，通过二项上界delta=.025估计。阈值只用12条正常阈值流，目标有限视界误报.10，预设有限样本秩。先冻结阈值再生成任何测试数据。

预设8方法：首次拒答、首次核对异常、滑窗5至少2异常、滑窗正常校准阈值、Bernoulli CUSUM固定log100/正常校准阈值、7lambda均匀混合e-CUSUM固定100/正常校准阈值。CUSUM p1=.3，若m>=.3取(m+1)/2；e网格沿用现有函数。不能看测试调参或只报告最好方法。

## 统计口径

每条正常40步流首次报警计正常视界误报。故障流第16步及以前报警属于提前报警，不算检出；变后24步内检出报告检出率及成功流平均延迟，另报告无提前报警流的受限延迟（漏检记25）。30条正常流在三档结果重复展示，但不当作90条。双侧95%二项区间仅作流间IID假设下的参考，不证明云服务独立或条件均值约束。

阈值100不等于40步内1%误报；原文的统计保证是满足前提的ARL控制。原论文：https://nejsds.nestat.org/journal/NEJSDS/article/59/text 。当前m的样本上界不自动证明未来任意条件均值约束。

## 完成与解释

所有预设位置、未定、失败尝试、零注入流及8方法全量保存。评分、载荷、缓存和时间顺序做离线重放审计。即使正常0/30，双侧95%区间上限约11.6%，不能确认5%误报目标。若校准阈值退化到首次异常、固定阈值在稀疏故障漏检，照实报告，不以测试修参数。
