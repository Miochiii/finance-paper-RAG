# RAG 配对答案盲审说明

- 来源文件 SHA-256：`018e78a10dfeb4835fc33b96ee8051d5fc83c9a86d5882cf768a1a4da1429af3`；随机种子：`20260927`；40 道题、80 条答案。
- `reviewer_1.csv` 与 `reviewer_2.csv` 是相同的空白盲审表，分别交给两名审阅者；`blind_answer_review.csv` 是未填写模板；完成并锁定标注前不要打开 `blind_answer_key.csv`。
- 每行独立审阅，不根据重复的问题猜测 A/B 条件；盲表不包含检索证据，因此本轮只评回答质量，不评证据忠实性。

## 填写规则

- `reference_adequate_0_1_U`：标准答案是否足以判定问题，1=足够，0=明显不足，U=需核 PDF。
- `explicit_refusal_0_1_U`：模型是否明确表示无法回答，1=是，0=否，U=不确定。
- `answer_quality_0_1_2_U`：0=错误或未回答，1=部分回答，2=实质正确，U=标准答案不足或需核 PDF。
- 对标准答案不足、引用原文存疑或回答看似正确但依据不足的情况，写明疑点并核对 PDF。
- 两名审阅者应分别填写盲表；锁定后才用密钥表揭盲和统计一致性。
- `analyze_rag_blind_review.py` 在填写未完成时只输出进度，不读取密钥；两份都完成后输出一致性和不含条件的分歧仲裁表。
- 独立仲裁者填写分歧表的 `final_*` 列后，使用 `--adjudication` 重跑，才得到正式的分条件配对摘要。
