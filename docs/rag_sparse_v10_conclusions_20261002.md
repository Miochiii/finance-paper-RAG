# V10结果解读与下一步

## 已完成

2480条新生成回答，全部响应ID唯一；校准560条，测试1920条。按论文分开校准/测试，阈值在任何测试生成之前锁定，全部8种预设方法完整报告。测试中1769条正常证据回答完整，151条数值故障回答给错目标值，核对信号检出151/151；拒答信号在这151条错误上全部为0。质量U和核对U均为0。

30条纯正常测试流（每流40步）所有方法均0报警，故障流无提前报警。下表是变后24步内的流级检出数，不是逐答案错误检出率。

## 当前结论

核对信号持续识别了直接作答但数值错误的回答，拒答在该故障机制下没有触发。这支持将正常来源事实核对用于此类错误监测。

这轮没有显示e-detector优于首次核对异常：固定100在稀疏故障下有明显漏检和延迟代价；正常校准型滑窗/CUSUM/e-detector阈值则因校准全零而接近首次异常，成绩与首次异常相同。不能将辅助阈值版本写成有独立累计检测优势。

这些结果也不证明首次异常规则在自然流量中普遍更好。所有方法都在容易、固定的正常题库上0报警，未比较出真实误报成本的差别。0/30的双侧95%二项区间上限约11.6%（仅在流间IID假设下），不能确认5%误报目标；e-detector阈值100也不是40步内1%误报的保证。

## 适用范围

10题、8篇来源均曾在开发中使用；本轮仅按4篇/4篇分组。测试实际来自其中5题/4篇。2480条是新响应数量，不是2480道独立问题。26种完全相同评分输入共享两轮缓存，共104次评分API响应。全部来自同供应商自动评价和MinerU原文，未证明独立真值、云模型独立性或未来条件均值上界。监测依据仍为正常原文，全库同步污染不适用。

25项测试、载荷/缓存/时序审计和图表检查通过；原始记录保留，未按测试结果调阈值、换题或替换生成。自动审批阻断时的检查点、后续明确授权记录也保留。

## 下一步

先补充更复杂的正常场景与无害证据变化，建立能检验误报代价的正常基线，再比较累计统计器。题目和来源范围应扩大，保持生成前准入、校准与测试分离；不要仅重复这批简单题目来增加名义样本量。

数值故障机制已验证，可沿用。新的参数选择或方法开发应另设阶段，再用新的冻结测试数据验证。当前结果适合报告“核对信号在受控数值错误上有效、固定累计方法对稀疏错误的代价”，尚不适合宣称提出的变点统计器更优。
