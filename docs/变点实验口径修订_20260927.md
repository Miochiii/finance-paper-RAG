# 变点实验口径修订（2026-09-27）

本项目的 E1–E7 当前是**代理序列上的合成漂移实验**。`edetector.py` 直接修改代理值来构造变点；因此检出率和延迟说明检测器对该类代理变化的反应，尚不能证明真实 RAG 故障会造成同样变化。2026-09-22 及更早的日志和 CSV 使用旧口径，应作为历史结果，不与修订后的结果混合制表。

## 数据与统计口径

- 166 条标注题按两个不同批次构造，原行序不是在线时间。模拟时先打乱**原始查询**，切成校准段与检验段，再分别归一化和滑窗；校准窗口不能包含检验查询。真正按时间到来的日志应使用 `--no-shuffle`。
- 窗口聚合后的相邻值共享查询。块自助和 E7 的自相关数值部分来自这种重叠，属于合成压力测试，不能称为线上自相关的测量。
- 如果校准段某代理恒定，归一化把相同值记为 0.5，把检验段中新出现的更大/更小值分别记为 1/0；这样稀有事件的新出现不会被恒定尺度抹掉。
- `m ≥ 检验池样本均值` 只是一项描述性检查。e-detector 的理论前提是逐时刻的条件均值 `E[X_t | 历史] ≤ m`，样本均值或分位数不能证明它。
- `binom` 只接受 0/1 序列。它对连续代理、滑窗均值无效；即使输入为 0/1，Clopper–Pearson 的覆盖解释仍依赖独立二项采样假设。
- 固定长度 `T` 下，未报警流按 `T+1` 右截尾。CSV 中 `arl_mean` 是**已报警流的条件均值**，`arl_restricted_mean` 是把未报警流计为 `T+1` 的样本均值，用来估计 `E[min(报警时间,T+1)]`；该期望不超过完整 ARL，但单次模拟的样本均值不是严格下界。有限 `T` 的报警概率也不等于 `α`。
- E3、E6 在一批模拟变前流上选阈值，并在另一批流上报告实际报警率。它们仍共享同一个经验查询池；目标 1% 与实际报警率可能不同，比较延迟时须同时报告实际值。
- E6 的两样本方法在参考窗收齐前不打分。单指标 EDD 在代理方向已翻正后统一注入上升漂移。
