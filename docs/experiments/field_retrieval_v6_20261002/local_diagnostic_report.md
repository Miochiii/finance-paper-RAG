## 固定设计

- 11道题均保留；原始题目、私有参考字段沿用上一轮冻结值。
- 两种检索各生成11条新回答，另外33条固定完整/遗漏/改错答案用于检查评分。
- 预先冻结rag_field_refusal规则，以新回答验证。
- 公开题干/字段/论文来源参与检索，标准字段和摘录在检索后用于评价。
- 两种检索均最多3段、6000字符原文；不根据回答或规范摘录选择配置。
- 自动评分门槛沿用：至少10题；合成对照U比例不高于20%；完整误报0；遗漏、改错各检出至少80%；U计入分母。
