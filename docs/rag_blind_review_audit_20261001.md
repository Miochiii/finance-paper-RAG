## 收到复核表以后

1. 对冻结文本、标签、ID 做校验，记录哈希；重新计算一致性，确认字段理解已统一。复核锁定后才进入仲裁。
2. 生成不含条件的分歧表；请未见过条件的仲裁者判定仍有分歧和 U 的回答。标准答案充分性先按题目核对论文，同一道题统一判定。保留原基准，修订参考答案形成新版本，避免根据哪个条件答得好来筛题。
3. 固定成功定义：标准答案足够、质量 2、明确拒答 0；不足或不确定的不偷算为失败。报告所有排除项、两条件分母，以及两条件均可判的配对数；以题目为配对单位比较成功、拒答及质量变化。
4. 对照人工拒答标签和现有自动代理，检查漏报、误报；根据独立正常数据校准变点输入与阈值。质量降级和拒答增加分别报告。
5. 继续采集独立正常请求与预设干预序列，控制故障开始位置、题目组成和缓存；用这些序列研究误报及检测延迟。固定 40 题重排仍是离线演示，不是独立线上误报率验证。

当前优先级是复核，不需要立即再花 API 成本扩大这批样本。
