# V12.1 表格计算与多条件查找

## 目的

V11 中既有题在顺序、去重与一般背景变化下均完整，无观察误报。V12.1 先增加问题结构复杂度：差值、比值、多条件筛选后的最大值。

## 数据与题目

27 道新候选、9 篇目标论文，每篇对应 3 种题型。论文此前用于开发，不能称为未见论文验证。所有候选保持 pending；自动准入不直接晋升正式评测集。

原文解析获得 153 个单元格，保存 MinerU 文件 SHA、表题、页码、原文行列和精确字符坐标。差值与比值使用十进制展示值，不暗中换算百分数。计算结果使用 ROUND_HALF_UP 保留四位小数，以 Fraction 独立复核。负数按实际数值比较；零分母、并列最大值、近似数及括号统计量拒绝构造。

初版 V12 仅找到 5 篇同论文的字段匹配表，未达到预定 18 题/7 篇来源门槛；保留失败准备，0 API 请求，0 新回答。

V12.1 保持原题与规则，加入仅用于排序的大小写、数学下标呈现规范化和公开字段别名。优先同篇表，否则从 38 篇已有 MinerU 论文中选另一张字段相关完整表。选中 7 张同篇表、2 张跨篇表，证据涉及 11 篇论文。没有使用论文标题、标准值或回答指导排序。返回原文逐字保留。部分表通过宽泛字段别名匹配，干扰强度分层报告，不能把所有表都称为强实验干扰。

## 筛选、核对与评分

1. 候选各做两轮来源与计算检查，最多 54 次逻辑请求。
2. 9 个目标表的正常/干扰证据各盲提取一次网格，再各做两轮来源检查，最多 54 次逻辑请求。该步骤不传标准事实或参考网格。
3. 准入核验独立提取值与正确来源的单元格对应、字段单位和表格轴。只有候选两轮检查、正常/干扰两组网格都通过才进入配对实验。失败全部保留，回答生成前筛选。
4. 至少 18 道配对题、7 篇目标论文，每类至少 6 道题，否则禁止生成回答。
5. 冻结正常网格核对计划：从盲提取网格按公开规则计算，不使用候选参考事实。正常和干扰条件始终用该冻结正常核对计划。
6. 最多 54 条全新回答，沿用温度 0、max_tokens 512 和原提示词。不按回答质量重试、修改或筛选。
7. 标准事实和核对各两轮评分；通常 216 次评分逻辑请求。有限格式和引文修复计入总上限。

完整轮通常最多 378 条逻辑请求返回；含有限格式/引文修复最多 810 次逻辑请求。网络失败按现有客户端最多重试一次。V11 的授权额度不移用为本轮授权。

## 分析与限制

按条件与题型报告完整、错误/遗漏、质量 U、核对 U。只有标准事实完整而核对不完整才计为误报。真实正常质量错误被核对标出属于错误检出。配对比较按题保存，不把同题同论文回答当独立样本。

参考侧和核对侧共享公开算术实现，语义检查及评分为同一供应商。独立提取及双轮一致不构成独立人工真值。程序审计检验数据流与派生完整性，不能消除共同偏差。

本轮不调整变点方法或阈值，不直接运行新变点序列。先观察更难正常题是否带来有代表性的质量波动，再决定下一批按论文分组的序列校准。

原始题目、标准事实、证据及 API 返回保留在工作项目。备份仓库仅复制代码、测试、协议、汇总和诊断元数据，不提交或推送 GitHub。
