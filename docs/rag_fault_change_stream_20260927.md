# 配对答案构造的变点流：拒答代理

- 使用 40 道既有正式题的配对答案；第 20 道之后将上下文切换为移除正确文献的版本。
- 同一批题随机重排 200 次（种子 20260927）；这些顺序共享答案，不能当成 200 条独立运行流。
- 检测器输入仅为答案侧拒答代理（explicit）；金标准文献、F1 和 LLM 正确性评分不进入检测器。
- 用未进入配对实验的 126 条既有答案估计拒答均值：3 次代理命中，二项分布单侧 95% 上界 m=0.0604。
- 统一使用 E-detector 混合统计量、固定阈值 100。校准上界的独立同分布前提及检测器的逐时条件均值前提在此数据上都未验证。

| 输入 | 正常重排中报警比例 | 变点前报警比例 | 变点后报警比例 | 无提前报警时检出比例 | 检出时平均延迟（查询数） |
|---|---:|---:|---:|---:|---:|
| raw | 0.000 | 0.000 | 1.000 | 1.000 | 4.5 |
| overlap | 0.000 | 0.000 | 1.000 | 1.000 | 4.5 |
| disjoint | 0.000 | 0.000 | 1.000 | 1.000 | 15.2 |

这些数字只描述固定题集的**顺序敏感性**，不构成真实误报率、检出率置信区间或线上检测延迟。
重叠窗口重复使用查询，其条件均值可能超过 m；此列只作为工程对照。
explicit 规则是本轮修订的可观测文本代理；旧规则会把 fin_009 正常答案误判为拒答。
