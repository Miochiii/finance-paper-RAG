# 正常证据压力实验 V11

## 动机

V10 的正常回答无质量错误和核对阳性，不能充分检验误报控制。先检查常见证据组织变化能否导致真实正常回答质量变化或核对误报。

## 冻结方案

使用 V8.2 经表格轴澄清的 17 道既有题和 11 篇既有论文。四个条件各最多 17 条全新回答：原始证据、片段顺序反转、按原文坐标求并集去重、同篇相关干扰在前。

构造仅使用公开题干、请求字段、论文文本和已有召回坐标。所有原始来源位置保留，不修改数值、单位或表头。干扰根据公开二元字面重合一次排序选定，排除基线片段及前后 250 字符，不使用标准值指导选择。

原始、反转和去重正文不超过 6000 字符；干扰条件不超过 8000 字符，干扰段不超过 1800 字符。长度与背景同时变化，结果不能单独归因于干扰内容。

## 准入与执行

1. 每个条件逐字核验冻结正常事实引文仍在证据中。
2. 51 个压力候选仅用题干和证据盲提取字段，再做两轮来源检查。仅在提取完整、字段值与单位等于冻结正常字段后准入。
3. 所有失败保留筛选记录；每个条件至少 10 道题、6 篇来源，否则不允许生成任何测试回答。
4. 回答生成前冻结案例和随机执行顺序。生成温度 0、max_tokens 512、提示词沿用既有配置。
5. 标准事实和核对各两轮评分。核对始终用冻结正常证据的事实；压力提取计划只作准入用途。
6. 不依据回答正确性重试、改题、改证据或筛选。截断、评分分歧和 U 原样保留。

## 分析

按条件和来源报告完整、错误/遗漏、U；与同题新基线比较质量变化。标准事实完整而核对不完整才计为误报。正常场景下真实错误回答被核对标出属于质量错误检出。

不修改变点检测方法和阈值；本轮不运行新序列，也不声称累计检测优于单次核对。题和论文已用于开发，自动评分同一供应商，不提供独立人工真值、独立样本误报界或自然流量泛化结论。

## 完整性与保存

输入、源码、MinerU 文件和准备数据都有 SHA-256 锁。离线审计重放公开构造、筛选、API 输入、原始返回及评分派生，核验回答都在准入锁之后生成。

原始题目、标准值、证据、回答及 API 记录保留在工作项目；备份仓库只同步代码、测试、协议、汇总和图。暂不提交或推送 GitHub。
