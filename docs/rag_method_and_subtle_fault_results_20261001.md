# 方法对照与隐蔽故障试验结果

## 本轮完成内容

完成两项工作：使用此前冻结的新生成序列做事后方法对照；从此前授权的40题中选出11题、11篇不同文献，完成四条件的44次新生成及176次自动评价。所有新实验输入、判分依据和512/4096token特征在API调用前冻结，生成前先审计证据，所有选定案例完整保留。

本轮结果说明：原有强故障试验可以验证检测能力，但尚不能证明检测算法优于简单规则；更隐蔽的质量下降会绕过拒答代理，短上下文相关性还会受前置干扰影响。

## 一、同一新生成序列的方法对照

所有方法使用相同逐请求拒答序列；正常测试20条流、故障测试10条流，每流30次，故障从第11次开始。追加方法是在原结果已知后选择，因此这张表属于事后探索，参数未利用测试调优。

|预设规则/方法|正常报警|提前报警|故障检出|平均变后延迟（请求）|
|---|---:|---:|---:|---:|
|第一次明确拒答|0/20|0/10|10/10|1.2|
|连续两次拒答|0/20|0/10|10/10|4.8|
|最近5次至少2次拒答|0/20|0/10|10/10|3.3|
|Bernoulli CUSUM，p1=.10、固定阈值log(100)|0/20|0/10|10/10|7.5|
|Bernoulli CUSUM，p1=.30、固定阈值log(100)|0/20|0/10|10/10|4.4|
|e-detector，原主阈值100|0/20|0/10|10/10|3.7|

其余正常校准配置及动态均值Page–Hinkley详见 `method_comparison_20261001/method_comparison.csv`，共11项。Page–Hinkley对照使用每步在线更新的运行均值。

正常阈值校准300次和正常测试600次拒答全部为0，多个算法的校准阈值退化为约0，表现接近第一次正分数就报警。即使各方法经验误报均为0/20，也没有证明它们已匹配相同的真实低误报预算。

当前数据尚不能证明e-detector有经验优势，也不能根据这张事后表宣称简单规则在自然流量中更好。后续正式比较须在新请求生成前冻结方法，并覆盖稳定运行中可能出现的正常难题/拒答，记录其任务性质及实际质量；不能把人为故障混入流后称为正常流。

## 二、四条件的配对质量结果

选题依据为已冻结的MinerU必要事实可用、至少2项事实引文实际出现在正常上下文、句子删除能保留其他引文、同来源文献最多1题。13题满足结构条件，按固定顺序选取11篇不同来源；没有按本轮答案好坏选题。

|条件|完整回答（质量2）|部分回答（质量1）|错误/未回答（质量0）|未定|规则拒答|相对正常质量下降|
|---|---:|---:|---:|---:|---:|---:|
|原正常证据|11|0|0|0|0|—|
|删除某项引文所在句子|10|1|0|0|0|1/11|
|相似主题的异源证据|0|3|8|0|8|11/11|
|保留完整证据，前置异源片段|11|0|0|0|0|0/11|

相似主题组有3条质量下降而继续作答，局部缺失组还有1条。总共4个新生成案例表明，质量下降时拒答可以保持0。它们是4个案例，不是4条故障流的漏检；本轮没有运行变点检测器。

两轮质量评价均来自同一服务，属于重复自动测量。判分事实来自此前冻结的MinerU原文依据，生成与评审载荷没有条件、qid或目标删除点编号。完整答题仅按必要事实质量2定义，拒答信号另报，没有以监控代理反过来定义质量真值。本轮无U不代表排除了自动评审的系统偏差。

### 删除引文的干预多数没有造成语义缺失

生成前证据审计发现，局部删除的11题中，10题仍能在其他位置找到支持必要事实的材料。只有fin_025满足“一项事实缺失、其余事实仍有支持”的预设条件；它的生成质量由2降至1，且没有拒答。

因此，这10个仍有支持的案例不能计作成功的轻故障，也不能用它们论证模型抵抗真实要点缺失。它们全部保留于主表，没有根据结果追加删改上下文。

后续局部缺失构造须以事实为单位检查所有同义表述及支持片段，并重新核验剩余事实。仅删除参考引文不够。修订构造需要独立版本，在答案生成前冻结；本轮案例不回改。

## 三、512token与完整输入相关性

同一个本地BGE模型在生成前分别使用512和4096token上限评分。44份输入在512均截断，4096均未截断，最长实际输入2212token。相关性缺口为1-sigmoid(logit)，不是正确率。

|条件|平均缺口512|平均缺口4096|
|---|---:|---:|
|原正常证据|0.0289|0.0219|
|删除引文句子|0.0943|0.0315|
|相似主题异源证据|0.7802|0.6837|
|保留完整证据，前置异源片段|0.2236|0.0220|

保留证据组的11条答案均完整，但512评分平均缺口从0.0289上升到0.2236；完整输入下0.0219与0.0220基本相同。这显示短输入特征对证据前置位置敏感，存在把无害上下文变化当作退化信号的风险。本轮没有估计这种风险的变点误报率。

### 完整输入仍不能保证发现部分回答

4个没有拒答的质量下降案例：

|qid|条件|变后质量|完整输入缺口（正常→干预）|
|---|---|---:|---|
|fin_025|实际缺失一个事实|1|0.000600→0.001012|
|fin_021|相似主题异源证据|1|0.110279→0.993333|
|fin_016|相似主题异源证据|1|0.009232→0.224055|
|fin_005|相似主题异源证据|1|0.005021→0.055515|

fin_025即使检查完整上下文仍高度相关，必要事实却已缺失，生成答案也不完整。因此，扩大输入长度可以改善位置/截断问题，仍不能把上下文相关性当作事实覆盖观测。这里只描述分数，不拟合阈值，也不把分数上升称为已检出。

## 四、下一阶段的具体顺序

1. 新辅助特征版本使用完整实际可见输入；保留512版本作消融对照。对新特征重新估计m与校准阈值，不能直接套用此前512版本的上界。
2. 改进局部事实缺失的构造：检查所有语义支持片段，删除后仍保留其他事实，生成前逐事实核验。只有合格干预才能进入该故障类别。
3. 设计“问题要求是否被回答”和“补充检索能否发现遗漏”的可部署覆盖观测。线上特征不能输入事先冻结的标准事实；这些事实仅用于离线检查代理是否有效。无标准答案时无法确定完整性的案例保留U。
4. 新题/文献按来源分开用于代理设计与检验；本轮11题是机制开发数据，不能再用于拟合参数后报告独立泛化性能。
5. 信号能稳定区分真正质量下降与保留证据对照后，再做变点后10%/30%/50%请求干预的弱变化长序列，并预先冻结比较方法和正常校准。干预比例不是错误率，要另行确认实际质量变化。

本轮机制结果不足以用“单句删除”批量生成正式轻故障流。长序列工作应建立在有效的语义干预和覆盖信号上。
